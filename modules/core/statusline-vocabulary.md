### Statusline Vocabulary — "issues N", "gk N", "skipped N" = the Footer Segment

**When the user says "issues N", "gk N", or "skipped N", they usually mean the airuleset statusline segment at the BOTTOM of Claude Code** (the footer next to the ctx meter) — not a GitHub query for you to invent (user directive, 2026-07-19). The segment's forms:

Every label was shortened on 2026-08-04 (#223 — dropped the ctx-fill bar, added the `sub`/account-email segments, and abbreviated every existing label so it all still fits on one line); the RENDERED forms below are current, the spoken forms above stay the natural way to refer to them.

- `I N` (was `Issues N`) — open non-`autopilot-skip` GitHub issues for THIS BOX's own slice, never automatically the whole repo: a full-authority (core/gatekeeper) box EXCLUDES every sub-dev stream's `stream:<user>`-labeled tickets (renders `I N core · str M` when the excluded population is known, so it never hides behind a bare number — #164); a reduced-authority sub-dev box counts only ITS OWN assigned/authored/stream-labeled slice.
- `I D/T` (was `Issues D/T`) — an ACTIVE autopilot run: D tickets done of T total (green when the backlog empties).
- `· gk N` — sub-dev boxes only: own tickets already handed off to the gatekeeper (`ready-for-review` label); gk 0 still renders.
- `· skip K` (was `· skipped K`) — tickets labeled `autopilot-skip` (excluded from runs); hidden at 0.
- `· gkq N` (was `· gk-req N`) — full-authority boxes only: open `needs-gatekeeper` tickets = sub-dev streamy čakajú na akciu supervízora (airuleset #30; kanál `airuleset.py gk-request`, doručenie watchdog job 11); hidden at 0. (Nezamieňať so sub-dev `· gk N` = vlastné tickety odovzdané gatekeeperovi.)
- `Q N` / `Q N · inde M` / `Q inde M` (was `otazky N` / …, own chunk next to the `I` segment) — UNANSWERED ❓ pings awaiting the user's reply, SCOPED to the session's project: orange `Q N` = pending questions asked from THIS repo, grey `inde M` = pending in other projects on this box. Source: the machine-local question map `~/.claude/discord-questions.json` (entry added per ❓ ping; dropped when the watchdog routes the Discord answer into the asking session, OR the moment the session gets a later HUMAN prompt — answered at the terminal; 24h TTL backstop). Hidden at 0.
- `sub <D.M.>(<Nd>)` — the monthly renewal anchor of the Claude account logged in on THIS box (`~/.claude.json` → `oauthAccount.subscriptionCreatedAt`); the next occurrence of that day-of-month, coloured by proximity (green far, yellow near, red on the last day).
- a faint account email at the end of the line (`~/.claude.json` → `oauthAccount.emailAddress`) — WHICH Claude account this box is logged in as.

The segment renders from machine-local caches — read THOSE when the user asks about it (never guess, never re-derive differently): `~/.claude/tickets-status/<cwd-key>.json` (refresh: `python3 ~/devel/airuleset/airuleset.py tickets-status --refresh --cwd <dir>`) and `~/.claude/autopilot-progress/<repo>.json`. A number the user quotes that mismatches your own `gh` count usually means a stale cache (TTL 120 s) or the per-stream scoping above — explain, don't dismiss. Applies to all rewordings ("v pätičke", "dole v claude", "ten counter").
