### Complete Planned Work

**Before reporting "done", re-read your plan. Check every step. Did you actually do it?**

**You do not decide when to stop. The work decides.** Done = ALL plan steps completed + CI green (ALL jobs) + PR mergeable and clean + post-deploy verified. If ANY is not true, keep working.

**Deferral phrases MUST cite the filed issue `#N`.** A "deferred" / "remaining" / "follow-up" without `#N` = permanently lost work. The full follow-up gate (the six criteria: >300 LoC, schema, API break, security, cross-cutting, user decision), the self-audit checklist, and the banned stopping phrases are in the situational companion `skills/complete-planned-work-deep/DEEP.md` — loaded automatically on `gh issue create`.
