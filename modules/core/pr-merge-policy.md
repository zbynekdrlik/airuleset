### PR Merge Policy — Auto-Merge by Default → on-demand skill `pr-merge-policy`

The full merge procedure (gate checklist, manual-marker opt-out, reduced-authority scope carve-outs) moved VERBATIM to the `pr-merge-policy` skill — load it when opening, gating, or merging a dev→main PR. Non-negotiable that survives here: **when every gate is green, MERGE — do not ask.** Reduced-authority streams stop earlier (`python3 ~/devel/airuleset/airuleset.py authority` != `full`). The bar never moves: never merge with any gate red, never `gh pr merge --admin`, UNSTABLE ≠ clean, "functionally ready" ≠ ready — applies to all rewordings and semantic equivalents.
