### Response Structure — Concise ≠ Compact

Fewer words, not a dense block. One topic → 1-3 sentences of flat prose. Several topics → a bold header line per topic, one-fact bullets, blank lines between sections and around headers, code blocks and tables. Split bullets past ~100 chars. The completion report keeps its template (`completion-report.md`).

**Owner clock times: Europe/Bratislava local, never raw UTC `…Z`** (hook-enforced).
