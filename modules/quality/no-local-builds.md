### Local Build Policy → on-demand skill `local-builds`

Tiered policy (Tier 0 default: **ZERO local cargo compilation** — owner directive 2026-08-18, #557: EVERY compiling cargo shape (build/test/bench/run/check/clippy/doc/rustc/install/… , narrow AND whole-workspace, `--no-run` or not) runs in CI ONLY; locally you may run only NON-compiling cargo (fmt/metadata/tree/clean/update) plus non-cargo lint. Hook `block-tier0-local-build.sh` enforces the ban deterministically as an allowlist inversion — an unknown/third-party compiling cargo subcommand fails safe to blocked. Tier 1 `=allowed`; Tier 2 `=fast-iterate` via `/fast-iterate` — both lift the ban entirely and are UNCHANGED by #557). Full tiers, pre-push gate commands, cross-compile cookbook and `target/` purge rules moved VERBATIM to the `local-builds` skill — load it BEFORE running or considering a local build, when the hook blocks you, or when auditing build-artifact disk.

**Shared-stream box = Claude-only; heavy JVM/Android/RN builds run on dev2 (#778, owner directive 2026-08-31).** A shared-stream box (subdev — the VPS running N isolated Claude stream users) exists ONLY for Claude sessions + git + light scripts/tests + the watchdog. A JVM/Android/React-Native build toolchain (JDK/Gradle/Kotlin daemon/aapt2, an Android emulator, a `qemu-system*` VM) is BANNED there — two streams ran `-Xmx3072m` Gradle/Kotlin daemons and collapsed the box (#774). Run every Android/JVM/RN build on **dev2** (`ssh newlevel@dev2` — the owner-designated build + emulator lane), never on a shared-stream box; CI/EAS is the complement, dev2 is the place. This is the per-box JVM/Android extension of the Tier-0 cargo doctrine above. Mechanically enforced on shared-stream boxes only: the `block-heavy-build-toolchain.sh` PreToolUse hook (Layer 1, blocks a launch) + the watchdog `heavy_build_reaper` Job 38 (Layer 2, kill-on-sight). A box is `shared-stream` per its `~/.claude/airuleset-box-class` marker; dev1/dev2/gk are `workstation` and neither is gated.
